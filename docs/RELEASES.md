# イーライ Releases & Future Revisions

## Generation 1 — イーライ

The original voicebank and the starting point of the project. It remains preserved as the first recorded form of the voice.

## Generation 2 — 茜音イーライ

The established second generation. The current technical documentation records three pitches (A3 / F3 / C3), improved phoneme clarity, a clearer upper range and an expanded expressive workflow.

This generation also marks a stronger feminine, queer and gender-nonconforming direction in the voice and character presentation.

## Generation 3 — 茜音イーライ・暁

The incoming third generation continues the same voicebank's development through:

- cleaned and rechecked existing samples;
- new append / expression recordings;
- additional extras and non-lyrical material;
- repaired or expanded aliases where needed;
- updated OpenUtau / UTAU configuration;
- fixed comparison phrases for regression testing;
- release manifest and checksums;
- generation-specific demos and documentation;
- a new visual design.

Current status: **IN DEVELOPMENT**. The repository already contains a generation-specific asset folder with placeholder artwork so the website can be prepared before the final design is complete.

## Development philosophy

A new generation does not erase the previous one. The voicebank grows by accumulating new ways to hear and use the same creative project.

暁 is deliberately more queer and more gender-nonconforming in its presentation than the generations before it. The direction follows the real voice provider's own movement toward a non-binary identity and a place between genders.

## Revision numbering

### 1.x — maintenance

Compatibility and repair releases within an established generation.

### 2.x — major expansion

Substantial expansion of the established second-generation bank, including new pitches, tone layers or technical coverage where applicable.

### 3.x — 暁 generation

The new recording and presentation stage. Earlier releases remain archived and usable while the third generation is developed.
