## Archive fields

For each work, record:

- title
- publication date
- creators and credits
- voicebank generation
- version / append when known
- the voicebank's role
- source URL
- related artwork or release post
- notes about the recording or use

The archive can contain demos, original songs, covers, MVs, UST/USTX examples, alternate mixes and community works.
